# Your own sound files

Upload your sound files here (GitHub: Add file > Upload files). Any common format works (mp3, wav, ogg, m4a): the
"Fetch audio into the app" step converts them to mp3 and packs them into the app.

Tips
- Short effects (under 5 seconds) are best. Normalise the loudness so they match each other.
- Name each file after what it is, for example `bat_hit_1.mp3`, `stumps_hit.wav`, `four_crowd.mp3`.
  Several files with the same name and a different number (`bat_hit_1`, `bat_hit_2`) can be played at random.
- Then tell the assistant which game moment each sound is for.

Nothing in this folder is used until the next patch connects it to the game.
